# CPP-modules

Este repositório contém a implementação dos módulos de C++ seguindo a metodologia do curso 42. O objetivo é aprofundar o conhecimento em C++ por meio de exercícios práticos e projetos desafiadores, abordando conceitos fundamentais e avançados da linguagem.

## Estrutura

O projeto está dividido em módulos, cada um focado em tópicos específicos do C++ tais como:

- Orientação a objetos
- Herança e polimorfismo
- Manipulação de memória
- Sobrecarga de operadores
- Templates
- Exceções

Cada módulo possui exercícios e exemplos práticos para fixação dos conceitos.

## Como usar

1. Clone este repositório:
    ```bash
    git clone https://github.com/RochtBruno/CPP-modules.git
    ```

2. Acesse o diretório desejado e utilize o `Makefile` para compilar os exercícios:
    ```bash
    cd CPP-modules/moduleXX
    make
    ```

3. Execute os binários gerados para testar as implementações.

## Requisitos

- Compilador C++ compatível com C++98 ou superior
- Make

## Objetivo

Este repositório serve de apoio para quem está estudando C++ no contexto do curso 42 ou para quem deseja praticar conceitos fundamentais e avançados da linguagem com exemplos práticos e desafios progressivos.
